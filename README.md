# Covenant 圣约 — 行走在神话语之中

一个**中文优先、可切换英文**的互动圣经故事冒险游戏。你不是在读关于大卫、但以理或以斯帖的故事——你**站在他们身旁**：甩出石子、潜过狮子坑、在风浪中掌舵、在麦田里拾穗、在深海中屏息、爬上桑树。

> 玩家是**见证者**。你的选择塑造你自己的品格，绝不改写圣经的结局。

**v0.4.1** 修好了真机上发现的两个问题（隐藏物品完成按钮被挤到屏幕外、大卫第二幕跳跃后飞走不再落地），全面审查了所有章节的关卡逻辑，并加入了**程序生成的环境音乐与环境音**。

**v0.4** 把每一章从「一个小游戏」升级成**多幕互动场景**：先准备、再闯关、最后才是高潮。大卫一章现在有三幕——练习甩石、在歌利亚的长枪下跑过山谷、最后才甩石迎敌；而溪边的「提灯搜寻」里你真正找到几块光滑石子，上阵时就只有几发弹药。全部 10 章都加了准备幕，另外新增 6 张人物立绘、电影感画面、以及需要拖动提灯才能找到的隐藏物品。

（v0.3 的内容保留：10 章、营地枢纽、3 位 NPC、3 个任务、昼夜循环、行囊与「引导」资源、呼吸祷告、沉浸／纯净模式，以及一个没有提示的终章。）

## 这一版有什么（v0.4）

### 每一章都是多幕互动（v0.4 核心改动）

旧版每章只有一个小游戏，而且「找五块石头」只是点五个发光点。现在：

- **多幕场景框架**（`src/engine/stages.js`）：每章先有 1–2 个「准备幕」，再进入原本的高潮关卡。准备幕有六种机制：**提灯拂沙搜寻、节奏点击、沿路拖行、蓄力松手、记忆序列、闪避奔跑**。幕与幕之间有「ACT CLEAR」过场、幕数徽章与整体进度条。
- **大卫一章有三幕**：① 练习甩石（蓄力／松手）；② 在歌利亚不断投来的长枪间点击跳跃，跑到阵前；③ 才是原有的甩石迎敌（风向、盾牌、命中额头两次）。
- **搜寻结果会带进战斗**：溪边故事节点的「提灯搜寻」从 5 块光滑石子和 6 块棱角假石中挑石子，**找到几块，甩石关卡就只有几发弹药**（最少 2 发）。跳过或灯火燃尽，你就得用更少的石头面对歌利亚。
- 其余 9 章各有一种主题化准备幕：但以理的「守夜祷告节奏」、耶利哥与浪子的「沿路拖行」、风浪与约拿的「蓄力松手」、以斯帖与撒该的「记忆序列」、摩西与路得的「拂沙搜寻／收割节奏」。
- **准备幕永远不会卡住剧情**：超时或失误会带着较低分数自动进入高潮幕。只有高潮幕决定奖励。

`npm run check:games` 会用 mock canvas 逐帧跑完全部 10 个多幕场景的 `step` 与 `draw`（含每一幕），捕捉运行时错误。

### 环境音乐与环境音（v0.4.1）

`src/core/audio.js` 现在除了音效，还会合成三层声音，**不需要任何音频文件**（离线与单文件版都能用）：

- **低频持续音**：根音／五度／八度三层振荡器，用 0.07Hz 的 LFO 做呼吸起伏。
- **环境底噪**：循环布朗噪声经低通滤波，模拟风声、水声、雨声或人群声；滤波频率缓慢扫动。
- **五声音阶旋律**：look-ahead 调度器随机游走生成柔和音符，带低通与慢速包络。

10 章映射到 7 种氛围（山谷／夜晚／沙漠／海洋／田野／圣殿／城市），营地与终章另有专属音色；切章时约 1 秒交叉淡化。浏览器禁止自动播放，所以在**第一次点击／按键**后才创建 AudioContext（不会报错、不会有警告）。标签页隐藏时自动静音以省电。

控制方式：标题页、地图 HUD、故事页右上角都有 ♪ 按钮；角色设置页有独立开关。偏好保存在本机。

### 更好的画面（v0.4）

- **6 张人物立绘**（`assets/art/portrait-*.jpg`）：文士以利亚斯、年轻英雄、巨人、女子、长者，以及一个**非具象的光之人形**（用于耶稣与神的声音——是否直接描绘基督，仍留给你们的团队决定）。对白框与场景里的大头像现在显示真正的脸，不再是一个字母圆圈。
- **电影感画面**（`src/engine/visual.js`）：所有关卡共享暗角、胶片颗粒、信箱式黑边、金色发丝线与四角装饰；每章另有专属**前景剪影层**（岩石、沙丘、麦秆、树枝、人群、波浪、石柱），画面有了近／中／远三层景深，并加了「黄金时刻」暖光分级。
- **对白场景**：插画区域加大、增加前景剪影与边框、章节副标题铭牌、底部淡淡的章节插画回响，不再是一大片空白。

### 提灯搜寻（隐藏物品重做，v0.4.1 已修交互）

- 找到的物品会**保持可见**（`revealed` 状态），提灯移开后不会重新变黑，避免玩家「找到了却点不到」。
- 完成面板改为**脱离文档流的底部浮层**，在所有 10 章都验证过按钮完整落在可视区域内；同时预留了 Android 导航栏的安全距离。
- 进入搜寻时会清掉上一幕遗留的奖励提示，避免遮挡标题。

### 搜寻规则

原本「点五个发光点」现在是真正的搜寻：整个画面在黑暗中，必须**拖动提灯**照亮，物品才会显现；浅色的**假物**会以假乱真，点错会消耗 3 点专注；另有 28 秒的灯火倒计时。失误 3 次或灯火燃尽则跳过奖励，但剧情照常继续。

### 10 章 · 10 个互动关卡
原来 6 章（以拉谷、狮子坑、耶利哥路、平静风浪、浪子、以斯帖）新增 4 章双语章节：

| 新章 | 关卡 | 玩法 |
|---|---|---|
| 燃烧的荆棘 | **desert** 跟随羊群 | 拖动走过沙丘找齐 3 只羊，在沙暴合拢前走到燃烧的荆棘 |
| 拾穗的麦田 | **glean** 日落前拾穗 | 拖动收集 12 捆麦子，避开 2 把挥动的镰刀，赶在日落前完成 |
| 大鱼腹中 | **deep** 潜入深海 | 上下拖动游泳，接住 3 颗祷告气泡，避开礁石与水母，游到岸边 |
| 爬上桑树 | **climb** 爬上桑树 | 按亮起的树枝交替点左／右，抓稳 10 次，在耶稣经过前爬到树顶 |

**更好的画面**：每个关卡都铺在对应章节的原创插画上，加了色彩分级、体积光束、视差平移、天气（雨／沙／落叶／火星／花瓣）、地面阴影、角色轮廓光与剪影。矢量精灵叠加在绘画背景上，离线也能跑。


### 营地枢纽（真正的冒险游戏中枢）
- **昼夜循环**：每完成一章进入新的一天，天空在黎明／清晨／正午／黄昏／夜晚之间轮转，太阳与星空随之变化。
- **3 位旅人**：文士以利亚斯、营地守护者米利暗、同行旅人迦勒。点击头像可读他们的三段对话（解释祷告、任务板与关卡操作）。
- **任务板**：守住篝火（3 章中祷告）、装满行囊（4 件圣物）、走过五条路（5 章）。全部完成可获得营地印记。
- **行囊**：圣物、果子、印记与「引导」数量一目了然。
- **呼吸祷告**：营火旁的迷你仪式。慢慢点击圆圈，吸气 → 停住 → 呼气，共三轮；每个营地日一次，获得 +2 引导与 +1 信心。

### 「引导」（Guidance）——祷告有了实际用途
- 每章按住祷告：**+1 信心、+4 经验、+1 引导**，并给出一句诗篇／经文应许。
- 营火呼吸祷告：**+2 引导 / 日**。任务奖励也提供引导。
- 引导的用途见下节。

### 沉浸／纯净模式（回答「圆圈是什么」）
设置里可以开启。开启后：

- 选项周围的**提示、品格门槛说明、奖励预览标签、以及那张小建议卡全部消失**。
- 被锁的金色选项仍然在，但只说「有些门要到后来才开」，不再告诉你缺什么。
- 花 **1 点引导**可以显明当前这一页的提示；花 **2 点引导**可以直接穿过一个品格还不够的门槛。
- **结局完全不变**：大卫仍然迎战歌利亚，风浪仍然止息。隐藏提示只改变你看门的清晰程度，不改变门后面的经文。

> 圆圈的含义（正常模式）：数字圆圈 = 选项序号；金色圆圈 = 与信心相关的选择；青色标签 = 品格／奖励预览；虚线带锁 = 尚未达到的品格门槛；祷告按钮上的动画 = 「按住填充」环，提示你要按住而不是轻点。

### 终章（没有提示的结尾）
走完 10 章后进入终章。它**不给分数、不给清单、不给提示圈**：只有你最突出的品格、你收集的圣物／果子／印记、一段关于「你的选择塑造了怎样的人」的诚实文字，以及一节经文（耶利米书 29:11）。没有圆圈告诉你该有什么感受。

### 其它保留／强化
- **默认简体中文**，一键切换英文；经文用和合本／KJV（皆公有领域）。
- 隐藏物品、可拖动的地图朝圣者、可滑动的选项卡、按住祷告、打字机对白、粒子／震屏／彩带。
- 四种品格、九种圣灵果子、**10 件圣物、9 枚印记**、书卷日志、角色卡、反思题、自动存档、程序化音效、PWA 离线缓存（`covenant-v6`）、Capacitor 打包配置。
- `npm run check` 现在报告：`Chapters: 10 · Nodes: 58 · Lines: 223 · Choices: 135`。

## 本地运行

```bash
npm install          # jsdom / esbuild（仅测试与单文件构建需要）
npm run dev          # 或 npm start — 在 4173 端口启动静态服务器
```

打开 `http://localhost:4173/`。源码是原生 ES modules，无需编译。

### 命令

```bash
npm run check        # 校验 10 章内容、链接与状态转移
npm run check:games  # 逐帧跑完 10 个多幕场景（含每一幕），捕捉绘制 / 逻辑错误
npm run check:acts   # 用「预言机」输入完整通关每个准备幕与高潮关卡，检查卡死 / NaN / 跳跃落地
npm run smoke        # 无头浏览器跑通 10 章 + 营地 + 任务 + 呼吸祷告 + 沉浸模式 + 终章 + 重置
npm run check:i18n   # 检查中英文界面完整性（含营地与终章）
npm run build:www    # 生成 www/（Capacitor 的 webDir）
npm run build:single # 生成 Covenant-offline.html（单文件离线版）
npm run smoke:single # 验证单文件版能独立运行
npm run build        # build:www + build:single
npm run icons        # 重新生成 PNG 图标（仅用 Python 标准库）
```

## 关键决定

- **一个代码库，两个平台**。同一套 PWA 通过 Capacitor 打包到 iOS 与 Android；原生工程未生成（需要 Xcode / Android Studio）。
- **中文优先，英文可切换**。语言偏好存 localStorage；切换时原地重建界面，不丢存档。
- **玩家是见证者**。互动关卡改变的是玩家的体验与品格，不是经文结局。
- **互动要服务故事**。每个关卡都从该章的具体处境长出来，而不是套一个通用小游戏。
- **提示是可选的**。沉浸模式把选择还原为「听故事、诚实选择」；引导资源让提示变成一种花费，而不是常驻的扶手。
- **无第三方运行时依赖**、无追踪、无广告、无账号。

## 你仍需决定的事

译本（和合本／新译本／英文 licensed 译本）、神学审阅流程、目标年龄层、本地化语言（简体／繁体／马来文／淡米尔文等）、是否直接描绘耶稣的形象。本作在「平静了吧」与「爬上桑树」中出现了耶稣的身影（剪影／远处行路的人），正式发布前请由你们的牧者团队决定如何处理。
